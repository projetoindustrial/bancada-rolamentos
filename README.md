# Bancada de Rolamentos

Simulador didático de rolamentos que roda no navegador, sem servidor: som, vibração, espectro e diagnóstico assistido por um controlador virtual. Instalável no celular e funciona offline depois de aberto uma vez.

**Abrir:** https://projetoindustrial.github.io/bancada-rolamentos/

## Aviso

Todos os sinais são **sintéticos** e o som é **estilizado**; os parâmetros são didáticos, não calibrados. Isto é uma demonstração e uma ferramenta de ensino: não é evidência experimental e não deve ser usado em decisões reais de manutenção.
