# Bancada de Rolamentos

Simulador didático de rolamentos que roda no navegador, sem servidor: rolamento em reservatório de vidro com nível de óleo, som, vibração, espectro, visão térmica e diagnóstico assistido por um controlador virtual. Instalável no celular e funciona offline depois de aberto uma vez.

**Abrir:** https://projetoindustrial.github.io/bancada-rolamentos/

## Aviso

Todos os sinais são **sintéticos**, o som é **estilizado** e a visão térmica é **ilustrativa**; os parâmetros são didáticos, não calibrados. Isto é uma demonstração e uma ferramenta de ensino: não é evidência experimental e não deve ser usado em decisões reais de manutenção.
